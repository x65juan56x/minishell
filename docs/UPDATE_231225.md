# Minishell Update — 23 December 2025

## Summary

This update focuses on memory leak fixes, code cleanup, and improving overall memory safety. All changes were verified with Valgrind to ensure zero leaks and zero errors.

---

## Memory Leak Fixes

### 1. Heredoc Filename Leak in Child Process

**File:** `src/executor/heredoc_executor.c`

**Problem:** The `temp_filename` passed to `heredoc_child_routine` was not freed before `exit()`, causing a 23-byte leak in the heredoc child process.

**Fix:** Added `free(filename)` before exit and changed parameter type from `const char *` to `char *`.

```c
// Before
static void heredoc_child_routine(const char *filename, ...)
{
    ...
    cleanup_child_process_deep(shell_context);
    if (result != 0)
        exit(1);
    exit(0);
}

// After
static void heredoc_child_routine(char *filename, ...)
{
    ...
    cleanup_child_process_deep(shell_context);
    free(filename);
    if (result != 0)
        exit(1);
    exit(0);
}
```

**Also updated:** `include/minishell.h` prototype for `execute_heredoc`.

### 2. Get Next Line Static Buffer Leak

**File:** `libs/get_next_line/get_next_line.c`

**Problem:** The GNL static buffer (`list_static`) was never freed, causing 14-byte "still reachable" memory in child processes.

**Fix:** Added cleanup support for `get_next_line(-1)` that frees the static buffer.

```c
// Added at the beginning of get_next_line()
if (fd == -1)
{
    ft_free_lst(list_static);
    list_static = NULL;
    return (NULL);
}
```

**Also updated:**
- `src/shell/cleanup.c`: Added `get_next_line(-1)` call in `cleanup_child_process_deep`
- `src/minishell.c`: Added `get_next_line(-1)` call in `cleanup_shell_context`

### 3. Inherited Input Line Leak in Child Processes

**Files:** 
- `include/minishell.h`
- `src/minishell.c`
- `src/shell/shell_loop.c`
- `src/shell/cleanup.c`

**Problem:** When the shell forks, child processes inherit the current input line allocated by the parent. This memory was never freed in children, causing 11-14 byte "still reachable" leaks.

**Fix:** Added `current_input` field to `t_shell_context` to track the current input line.

```c
// include/minishell.h - Added to t_shell_context
typedef struct s_shell_context
{
    ...
    char            *current_input;  // NEW
}   t_shell_context;

// src/shell/shell_loop.c - Track input before processing
shell_context->current_input = input;
process_input(input, shell_context);
shell_context->current_input = NULL;

// src/shell/cleanup.c - Free in child cleanup
if (shell_context && shell_context->current_input)
{
    free(shell_context->current_input);
    shell_context->current_input = NULL;
}
```

### 4. Expand Curly Brace Leak

**File:** `src/parser/expander_utils.c`

**Problem:** In `expand_curly`, if `${VAR` was missing the closing `}`, the `env_value` was leaked.

**Fix:** Free `env_value` before returning empty string.

```c
// Before
if (token->value[*i] != '}')
    return (ft_strdup(""));  // LEAK: env_value not freed

// After
if (token->value[*i] != '}')
    return (free(env_value), ft_strdup(""));
```

### 5. Heredoc Preprocessor Node Leak / Segfault

**File:** `src/executor/heredoc_preprocessor.c`

**Problem:** In `process_heredoc_node`, if `ft_lstnew` failed, accessing `new_list_node->content` would segfault. If `ft_strdup` failed but `ft_lstnew` succeeded, the node would leak.

**Fix:** Split the NULL checks to handle both cases properly.

```c
// Before
new_list_node = ft_lstnew(ft_strdup(temp_filename));
if (!new_list_node || !new_list_node->content)  // Segfault if new_list_node is NULL
    return (free(temp_filename), -1);           // Leak of node if content is NULL

// After
new_list_node = ft_lstnew(ft_strdup(temp_filename));
if (!new_list_node)
    return (free(temp_filename), -1);
if (!new_list_node->content)
{
    free(new_list_node);
    return (free(temp_filename), -1);
}
```

### 6. Heredoc Read Input Return Value

**File:** `src/executor/heredoc_utils.c`

**Problem:** `create_heredoc_file` ignored the return value of `read_heredoc_input`, not properly handling EOF cases.

**Fix:** Propagate the return value and close fd on error.

```c
// Before
read_heredoc_input(delimiter, fd, shell_context);  // Ignored return
close(fd);
return (0);

// After
if (read_heredoc_input(delimiter, fd, shell_context) != 0)
    return (close(fd), 1);
close(fd);
return (0);
```

## Valgrind Warning Fix

### Uninitialized termios Structure

**File:** `src/executor/heredoc_executor.c`

**Problem:** `struct termios orig_termios` had uninitialized padding bytes that Valgrind detected when passed to `tcsetattr`.

**Fix:** Zero-initialize the structure before use.

```c
// Before
struct termios  orig_termios;
tcgetattr(STDIN_FILENO, &orig_termios);

// After
struct termios  orig_termios;
ft_bzero(&orig_termios, sizeof(orig_termios));
tcgetattr(STDIN_FILENO, &orig_termios);
```
